vps-setup
Cara pakai Perintah Keamanan GitHub

Server baru, tanpa hafal perintah.

Setup interaktif untuk server Linux yang baru dibeli. Pilih dari menu, jawab beberapa pertanyaan sederhana, review, lalu jalan.

$ curl -fsSL https://raw.githubusercontent.com/orlinkzz/vps-setup/main/install.sh | sudo bash

Lebih suka cek dulu isinya? Pakai git clone atau mode --dry-run.
Mendukung Ubuntu 22.04 / 24.04, Debian 12, dan AlmaLinux / Rocky 8 / 9.

Empat langkah, tanpa tebak-tebakan

    
Kamu yang pegang kendali. Tidak ada yang berubah di server sebelum kamu setuju.

    
    
      
  1. Jalankan
    Install lewat satu baris perintah, atau clone repo lalu jalankan setup.sh.
    2. 
      
  2. Pilih dari menu
    Centang yang kamu butuhkan: web server, database, domain, dan lainnya.
    3. 
      
  3. Jawab pertanyaan
    Hanya pertanyaan sederhana, seperti nama domain atau nama database.
    4. 
      
  4. Review lalu jalan
    Lihat ringkasan dulu. Kalau sudah sesuai, lanjutkan.

Perintah yang paling sering dipakai

    
Semua opsi ada di repo. Ini yang paling berguna untuk mulai.

    

      

        
Clone dan jalankan

        
Cara yang direkomendasikan kalau kamu mau baca skripnya dulu.

        
$ git clone https://github.com/orlinkzz/vps-setup.git
$ cd vps-setup && sudo ./setup.sh

      

      

        
Preview tanpa mengubah apa pun

        
Mode --dry-run hanya menampilkan apa yang akan dilakukan.

        
$ sudo ./setup.sh --dry-run

      

      

        
Pakai Bahasa Indonesia

        
Menu dan pertanyaannya tampil dalam Bahasa Indonesia.

        
$ sudo ./setup.sh --lang id

      

      

        
Tambah website nanti

        
Server sudah jalan? Tambah domain baru kapan saja.

        
$ sudo ./setup.sh --add-domain

      

      

        
Buat database nanti

        
Tambah database baru lewat menu interaktif.

        
$ sudo ./setup.sh --add-database

      

      

        
Mode otomatis untuk skrip

        
Lewati pertanyaan dengan preset, misalnya database PostgreSQL.

        
$ sudo ./setup.sh --yes --preset database --engine postgresql --db myapp

      

    

  






  

    
Aman dicoba, gampang dibatalkan

    
Mengubah konfigurasi server itu menakutkan. Makanya ada pengaman di setiap sisi.

    

      
File dibackup
File yang diganti disimpan ke /var/backups/vps-setup/. File hanya ditulis ulang kalau isinya memang berubah.

      
Semua tercatat
Setiap langkah masuk ke /var/log/vps-setup.log. Password tidak pernah ikut dicatat.

      
Bisa rollback
Skrip uninstall menghapus file dan konfigurasi yang dibuat vps-setup, dan mengembalikan file dari backup bila perlu. Data penting seperti database dan login root MySQL sengaja dibiarkan; skrip menunjukkan cara menghapusnya.

    

    
Sekalian urusan operasional

    
Selain setup awal, ada bekal untuk menjaga server tetap sehat.

    

      Backup database dengan rotasi
      Health monitoring (vps-setup-health)
      Jail fail2ban untuk Nginx: http-auth, botsearch, bad-request
